# Daniel Priestley — source material

Source: *Key Person of Influence* (Revised Edition, 2014) by Daniel Priestley — the Five-Step
KPI Method (Pitch / Publish / Product / Profile / Partnership).

Unlike the Sam Stoffel folder (which holds the original purchased course PDFs), this book's
text was provided via a pasted document attachment in-conversation rather than as a
locally-stored file. `extraction-notes.md` in this folder is a structured set of chapter-bychapter notes — frameworks, tactics and short attributed quotes — made from that text for
personal research, to support the Guru Vault entry at
`../Guru Vault/data.js` (id: `daniel-priestley`). It is not a verbatim copy of the book and is
not intended for redistribution; treat it the same way as the Sam Stoffel PDFs — personal
reference only, summarised under fair-use/research terms, not affiliated with the author or
publisher.
